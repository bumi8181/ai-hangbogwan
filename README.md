# AI 행보관

중대 통합관리 **시연용** 대시보드입니다. 모든 인원·장비·물자 데이터는 가상입니다.

- 총괄 대시보드: 총원·열외현황, 시설·차량·물자의 정상/불량
- 인사: 인원 추가·삭제, 생활관·상태 관리
- 군수: 3D 창고(일반창고·전투물자 창고·탄약고), 박스별 내용물·수량
- 시설·차량: 주둔지 배치도, 주차장 4열 × 10면

## 구성
- 단일 `index.html` (Vercel 정적 배포)
- 데이터: Supabase `hangbo_state` 테이블 1행을 모든 방문자가 공유하고 실시간 동기화합니다. 서버에 연결할 수 없으면 브라우저 저장소를 사용합니다.

> 시연용 공유 데이터입니다. 주소를 아는 누구나 내용을 고칠 수 있으므로 실제 정보는 입력하지 마세요.
